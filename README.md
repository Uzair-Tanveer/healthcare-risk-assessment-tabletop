# Cybersecurity Risk Assessment and Ransomware Tabletop Exercise

## Project Summary
This repository contains a fictional, consulting-style cybersecurity risk assessment and ransomware tabletop exercise for a small healthcare provider subject to HIPAA.

The project demonstrates:
- cybersecurity risk assessment
- control gap analysis
- framework mapping
- ransomware tabletop exercise facilitation
- executive risk communication
- remediation roadmap development
- after-action reporting
- improvement planning

## Fictional Organization
**Riverside Family Health Partners**  
A fictional small outpatient healthcare provider with:
- 1 clinic location
- telehealth services
- approximately 40–60 employees
- exposure to HIPAA-regulated electronic protected health information (ePHI)

## Purpose of the Project
This project was created for portfolio and educational purposes to demonstrate skills relevant to:
- GRC Analyst
- Cybersecurity Analyst
- Security Compliance Analyst
- Cybersecurity Advisor
- Junior Security Engineer
- Risk Analyst

## Frameworks Used
Where appropriate, this project maps findings and recommendations to:
- NIST Cybersecurity Framework (CSF)
- NIST SP 800-53
- CIS Controls
- HIPAA
- CMMC
- PCI DSS
- ISO 27001

## Repository Contents
- `docs/` — assessment documents, risk register, roadmap, executive briefing, after-action report, improvement plan
- `scenarios/` — tabletop exercise materials
- `tables/` — CSV versions of key artifacts
- `assets/` — optional diagrams and screenshots

## Important Disclaimer
This is a fictional scenario created for portfolio use only.  
No real organization, client, patient data, security incident, certification, or audit result is being represented here.
