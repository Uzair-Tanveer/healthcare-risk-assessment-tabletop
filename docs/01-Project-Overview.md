# 01. Project Overview

## Purpose
This project presents a fictional cybersecurity consulting engagement for a small healthcare provider. It includes a risk assessment, control-gap analysis, ransomware tabletop exercise, and remediation roadmap.

## Fictional Organization
**Riverside Family Health Partners** is a fictional outpatient healthcare provider that operates:
- 1 clinic location
- telehealth services
- approximately 40–60 employees

## Project Objectives
The objectives of this project are to:
- assess cybersecurity risk in a regulated healthcare environment
- identify critical assets and sensitive data
- map existing and needed controls to relevant frameworks
- evaluate readiness for a ransomware event
- produce executive-facing recommendations
- create a practical remediation roadmap

## Scope
This project focuses on:
- patient-facing and administrative business processes
- identity and access management
- endpoint protection
- email security
- backups and recovery
- incident response preparedness
- third-party/vendor risk
- HIPAA-related considerations

## Out of Scope
This project does not include:
- real organizational data
- real patient records
- real audit results
- actual legal advice
- actual penetration testing
- real vendor contracts
- real incident history

## Assumptions
This fictional organization is assumed to:
- rely on electronic health records and Microsoft 365 or similar collaboration tools
- handle electronic protected health information (ePHI)
- have limited internal security staffing
- depend on third-party vendors for some services
- be highly impacted by ransomware or extended downtime

## Deliverables
This repository includes:
- business context
- asset inventory
- current-state security controls
- control-gap assessment
- risk register
- cybersecurity roadmap
- executive briefing
- tabletop exercise materials
- after-action report
- improvement plan
- framework mapping
